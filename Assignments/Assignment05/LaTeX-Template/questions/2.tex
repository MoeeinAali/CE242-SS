\[
y(t) = x(t - 1) + \int_{-\infty}^{t} e^{-(t-\tau)} x(\tau - 1) d\tau
\]

برای پیدا کردن پاسخ ضربه، فرض می‌کنیم ورودی سیستم یک تابع ضربه واحد باشد، یعنی $x(t) = \delta(t)$. با جایگذاری در رابطه فوق داریم:
\[
h(t) = \delta(t - 1) + \int_{-\infty}^{t} e^{-(t-\tau)} \delta(\tau - 1) d\tau
\]

با توجه به خاصیت غربال‌گری تابع ضربه، انتگرال فوق تنها زمانی مقدار دارد که بازه انتگرال‌گیری شامل نقطه تغییر آرگومان ضربه (یعنی $\tau = 1$) باشد. این شرط معادل با $t \ge 1$ یا به عبارتی ضرب در تابع پله واحد $u(t - 1)$ است:
\[
\int_{-\infty}^{t} e^{-(t-\tau)} \delta(\tau - 1) d\tau = e^{-(t-1)} u(t - 1)
\]

بنابراین پاسخ ضربه سیستم برابر است با:
\[
h(t) = \delta(t - 1) + e^{-(t-1)} u(t - 1)
\]

\subsectionaddtolist{ب}

برای بررسی معکوس‌پذیری و محاسبه پاسخ ضربه سیستم معکوس، ابتدا تبدیل لاپلاس پاسخ ضربه سیستم اصلی را محاسبه می‌کنیم. 
با استفاده از خاصیت جابجایی زمانی:
\[
\mathcal{L}\{\delta(t-1)\} = e^{-s}
\]
\[
\mathcal{L}\{e^{-t} u(t)\} = \frac{1}{s + 1} \quad \Rightarrow \quad \mathcal{L}\{e^{-(t-1)} u(t-1)\} = \frac{e^{-s}}{s + 1}
\]

بنابراین تابع تبدیل سیستم اصلی عبارت است از:
\[
H(s) = e^{-s} + \frac{e^{-s}}{s + 1} = e^{-s} \left( 1 + \frac{1}{s + 1} \right) = e^{-s} \left( \frac{s + 2}{s + 1} \right)
\]
چون $H(s)$ به ازای مقادیر مشخصی صفر نمی‌شود، سیستم معکوس‌پذیر است. تابع تبدیل سیستم معکوس برابر است با:
\[
H_{inv}(s) = \frac{1}{H(s)} = e^{s} \left( \frac{s + 1}{s + 2} \right) = e^{s} \left( 1 - \frac{1}{s + 2} \right) = e^{s} - \frac{e^{s}}{s + 2}
\]

حالا با گرفتن عکس تبدیل لاپلاس و اعمال جابجایی زمانی $e^{s}$، پاسخ ضربه سیستم معکوس به دست می‌آید:
\[
h_{inv}(t) = \delta(t + 1) - e^{-2(t + 1)} u(t + 1)
\]

\subsectionaddtolist{ج}

یک سیستم زمان-پیوسته LTI علی است اگر و تنها اگر پاسخ ضربه آن به ازای زمان‌های منفی صفر باشد.

با نگاه به پاسخ ضربه سیستم معکوس به دست آمده در بخش قبل:
\[
h_{inv}(t) = \delta(t + 1) - e^{-2(t + 1)} u(t + 1)
\]
مشاهده می‌شود که به دلیل وجود جملات $\delta(t + 1)$ و $u(t + 1)$، این پاسخ ضربه از زمان $t = -1$ شروع می‌شود. به عبارت دیگر:
\[
h_{inv}(t) \neq 0 \quad \text{for} \quad -1 \le t < 0
\]

چون پاسخ ضربه سیستم معکوس در بازه $t < 0$ صفر نیست، سیستم معکوس به دست آمده {علی نیست}. از دیدگاه فیزیکی نیز وجود جمله $e^s$ در تابع تبدیل نشان‌دهنده نیاز سیستم به پیش‌بینی آینده است.
