$\bullet$ ویژگی Outlook دارای سه مقدار است: Sunny ، Overcast ، Rain

\setLTR
\begin{enumerate}
	\item Outlook = Sunny
	
	\[
	Entropy(Sunny) = -(\frac{2}{5}\log_2{\frac{2}{5}} + \frac{3}{5}\log_2{\frac{3}{5}})
	\approx 0.528+0.442=0.971
	\]
	
	\item Outlook = Overcast
	
	\[
	Entropy(Overcast) = -(\frac{4}{4}\log_2{\frac{4}{4}} + \frac{0}{4}\log_2{\frac{0}{4}})
	 = 0 + 0 = 0
	\]
	
	\item Outlook = Rain

	\[
	Entropy(Rain) = -(\frac{3}{5}\log_2{\frac{3}{5}} + \frac{2}{5}\log_2{\frac{2}{5}})
	\approx 0.442+0.528=0.971
	\]
\end{enumerate}
\setRTL 

محاسبه Information-Gain برای Outlook :


\[
Gain(S,Outlook) = Entropy(S) - (\frac{5}{14}\times0.971 + \frac{4}{14}\times0 + \frac{5}{14}\times0.971) = 0.940 - 0.694 = 0.246
\]

	\[
	Entropy(Hot) = -(\frac{2}{4}\log_2{\frac{2}{4}} + \frac{2}{4}\log_2{\frac{2}{4}})

	\item Temperature = Mild
	
	\[
	Entropy(Mild) = -(\frac{4}{6}\log_2{\frac{4}{6}} + \frac{2}{6}\log_2{\frac{2}{6}})

	\]
	
	\item Temperature = Cool
	
	\[
	Entropy(Cool) = -(\frac{3}{4}\log_2{\frac{3}{4}} + \frac{1}{4}\log_2{\frac{1}{4}})

\end{enumerate}

\]

\begin{itemize}
	\item وقتی مدل تصمیم‌گیری بیش از حد به جزئیات داده‌های آموزش وفادار باشد.  مثلاً: استفاده از ویژگی‌های کم‌ارزش یا نادر برای جدا کردن نمونه‌ها.
	
	\item حذف شاخه‌هایی که اطلاعات زیادی به مدل نمی‌دهند. (Pruning) تقسیم داده‌ها برای ارزیابی عملکرد مدل روی داده‌های ندیده‌شده. (Cross-validation)
	
	\item خیر. چون 3ID به شدت به داده‌های آموزشی وابسته است و نمی‌تواند با داده‌های نویزی یا ناقص به خوبی کنار بیاید. الگوریتم‌هایی مثل Random-Forest مقاوم‌تر هستند.
\end{itemize}
