\[
y(t) = e^{-|\alpha t|}\cos(\beta t)
\]

برای بررسی انرژی و توان، ابتدا انرژی کل را محاسبه می‌کنیم:
\[
E_{\infty} = \int_{-\infty}^{\infty} |y(t)|^2\,dt = \int_{-\infty}^{\infty} e^{-2|\alpha t|}\cos^2(\beta t)\,dt
\]


اگر \(\alpha \neq 0\)، چون \(|\alpha t|=|\alpha||t|\)، عبارت \(e^{-2|\alpha||t|}\) با افزایش \(|t|\) به صورت نمایی کاهش می‌یابد. همچنین:
\[
0 \le \cos^2(\beta t) \le 1
\]

بنابراین:
\[
0 < E_{\infty}
\le
\int_{-\infty}^{\infty} e^{-2|\alpha||t|}\,dt
=
\frac{1}{|\alpha|}
< \infty
\]

پس سیگنال انرژی محدود و مثبت دارد و یک سیگنال انرژی است.

حال برای بررسی توان متوسط داریم:
\[
P_{\infty}
=
\lim_{T\to\infty}
\frac{1}{2T}
\int_{-T}^{T} |y(t)|^2\,dt
\]

از آنجا که \(E_{\infty}\) محدود است، داریم:
\[
P_{\infty}
=
\lim_{T\to\infty}
\frac{E_T}{2T}
=0
\]

پس سیگنال توان نیست، چون برای سیگنال توان باید داشته باشیم:
\[
0 < P_{\infty} < \infty
\]

در نتیجه، برای \(\alpha \neq 0\) ، سیگنال داده‌شده یک سیگنال انرژی است، نه سیگنال توان.

ولی برای \(\alpha=0\) ، سیگنال به \(y(t)=\cos(\beta t)\) تبدیل می‌شود. در این حالت انرژی نامتناهی است و توان متوسط محدود و مثبت است؛ پس برای \(\alpha=0\)، سیگنال توان است.
