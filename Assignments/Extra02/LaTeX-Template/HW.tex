  \مسئله{

فرض کنید $x[n]$ و $y[n]$ دنباله‌های مختلط باشند و
$X(e^{j\omega})$ و $Y(e^{j\omega})$ تبدیل فوریهٔ آن‌ها باشند.
\begin{itemize}
\item[(الف)] با استفاده از قضیهٔ کانولوشن و خواص مناسب، دنباله‌ای را بر حسب $x[n]$ و $y[n]$ بیابید که تبدیل فوریهٔ آن برابر با
$X(e^{j\omega}) Y^*(e^{j\omega})$ باشد.

\item[(ب)] با استفاده از نتیجهٔ قسمت (الف) نشان دهید که:
\[
\sum_{n=-\infty}^{\infty} x[n] y^*[n]
=
\frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) Y^*(e^{j\omega}) \, d\omega
\]
\end{itemize}}
