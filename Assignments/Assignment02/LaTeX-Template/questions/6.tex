{بخش اول (سیستم سمت چپ):}
\[v[n] = x[n] - \frac{1}{3}v[n-1] - \frac{1}{2}v[n-2] \implies V(e^{j\omega}) = \frac{X(e^{j\omega})}{1 + \frac{1}{3}e^{-j\omega} + \frac{1}{2}e^{-j2\omega}}\]

\[w[n] = v[n] - \frac{1}{2}v[n-2] \implies W(e^{j\omega}) = V(e^{j\omega}) \left(1 - \frac{1}{2}e^{-j2\omega}\right)\]

\[H_1(e^{j\omega}) = \frac{W(e^{j\omega})}{X(e^{j\omega})} = \frac{1 - \frac{1}{2}e^{-j2\omega}}{1 + \frac{1}{3}e^{-j\omega} + \frac{1}{2}e^{-j2\omega}}\]

{بخش دوم (سیستم سمت راست):}
\[y[n] = w[n] - y[n-1] - 2y[n-3] \implies Y(e^{j\omega}) \left(1 + e^{-j\omega} + 2e^{-j3\omega}\right) = W(e^{j\omega})\]

\[H_2(e^{j\omega}) = \frac{Y(e^{j\omega})}{W(e^{j\omega})} = \frac{1}{1 + e^{-j\omega} + 2e^{-j3\omega}}\]

{تابع انتقال کل سیستم:}
\[H(e^{j\omega}) = H_1(e^{j\omega}) \cdot H_2(e^{j\omega}) = \frac{1 - \frac{1}{2}e^{-j2\omega}}{\left(1 + \frac{1}{3}e^{-j\omega} + \frac{1}{2}e^{-j2\omega}\right)\left(1 + e^{-j\omega} + 2e^{-j3\omega}\right)}\]

\[H(e^{j\omega}) = \frac{1 - \frac{1}{2}e^{-j2\omega}}{1 + \frac{4}{3}e^{-j\omega} + \frac{5}{6}e^{-j2\omega} + \frac{7}{3}e^{-j3\omega} + \frac{7}{6}e^{-j4\omega} + e^{-j5\omega}}\]

{معادله تفاضلی سیستم:}
\[y[n] + \frac{4}{3}y[n-1] + \frac{5}{6}y[n-2] + \frac{7}{3}y[n-3] + \frac{7}{6}y[n-4] + y[n-5] = x[n] - \frac{1}{2}x[n-2]\]

{پاسخ ضربه بازگشتی ($h[n]$ به ازای $x[n] = \delta[n]$):}
\[h[n] = \delta[n] - \frac{1}{2}\delta[n-2] - \frac{4}{3}h[n-1] - \frac{5}{6}h[n-2] - \frac{7}{3}h[n-3] - \frac{7}{6}h[n-4] - h[n-5]\]
